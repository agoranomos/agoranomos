# Tutorials

Tutorials are lessons. Each one guides you through a complete, small task from start to finish, so that you learn by doing and end up with something that works. They assume no prior knowledge of Agoranomos.

## Planned tutorials

- **Run Agoranomos locally with demo data**, arriving in v0.2.0, when the full demo generator comes. You start the stack on your own machine, load generated demo data (no ad platform accounts or API keys needed) and open the first dashboards. One demo path, from a demo source to a dashboard, ships earlier, in v0.1.0, and the how-to guide [See the demo](../how-to/see-the-demo.md) describes it.

Agoranomos is pre-alpha and not ready for use yet, so there is no tutorial to follow today.
